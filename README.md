# Sully

A Windows tool that reads the monthly user list, fills in the user counts on the "2. Beperk Verhalings" workbook, and splits subscription invoices (PDF) over business units and branches.

## Download and use

1. Click `Sully-to-send.zip` in the file list above, then click the download button.
2. Unzip it and double-click `Sully.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. The steps are in `HOW TO USE.txt` inside the zip.

If your browser or chat app blocks the `.exe`, download `Sully-for-chat.zip` instead and follow `READ THIS FIRST.txt` inside it.

## Build from source

Install Python 3, then run `build.bat`. The program is created in the `dist` folder.
